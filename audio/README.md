# 배경 음악 (BGM)

## 트랙

- **The Jam — Slynk & Mr Stabalina**
- 출처: YouTube Audio Library (사용자가 제공한 원본 MP3)

## 전달 파일

| 파일 | 포맷 | 용도 |
|---|---|---|
| `bgm.m4a` | AAC-LC 128kbps, 44.1kHz, 스테레오 | 주 소스 (Safari·Chrome·Android WebView) |
| `bgm.ogg` | Opus 96kbps, 48kHz, 스테레오 | 폴백 (Chromium·Firefox) |

## 처리

- 원본 320kbps MP3, 2:41.28
- 끝의 무음 2.8초를 잘라 **158.45초**로 루프 길이를 맞춤
- 통합 라우드니스 **−18 LUFS**, 트루피크 **−6.6 dBTP** (원본 −8.8 LUFS / +1.0 dBTP)
- 게임 내 기본 음악 볼륨 50%, 모달·오프닝에서는 35%로 덕킹

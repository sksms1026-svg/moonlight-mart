달빛 편의점

작은 가게에서 시작하는, 아주 느긋한 장사 이야기

v0.4.0 · 웹 / Android
바로 플레이하기 웹 Android APK 내려받기 0.4MB

1 Android — APK 설치

  1. 위의 APK 내려받기를 누릅니다.
  2. 다운로드가 끝나면 알림을 눌러 설치합니다.
  3. "출처를 알 수 없는 앱" 안내가 뜨면 허용을 선택합니다.
  4. Play 프로텍트 경고가 뜨면 무시하고 설치를 누릅니다.

설치 후 서랍에 달빛 편의점 아이콘이 생깁니다. 가로 화면으로 실행됩니다.

2 Android — APK 없이 설치 (PWA)

  1. Chrome에서 이 페이지를 엽니다.
  2. 오른쪽 위 ⋮ 메뉴 → 앱 설치 (또는 홈 화면에 추가).
  3. 홈 화면 아이콘으로 실행하면 주소창 없이 전체 화면으로 열립니다.

3 iPhone / iPad

  1. Safari로 이 페이지를 엽니다.
  2. 하단 공유 → 홈 화면에 추가.
  3. 홈 화면의 달빛 편의점 아이콘으로 실행합니다.

세이브 데이터는 실행한 브라우저/앱에 저장됩니다. 웹과 APK의 세이브는 서로 공유되지 않습니다.
APK는 팬메이드 디버그 서명 빌드입니다. Android 6.0 이상에서 동작합니다.

달빛 편의점

안드로이드 설치 파일 · 0.9.0
APK 내려받기
32MB · Android 7.0 이상
플레이 스토어를 거치지 않는 설치 파일입니다. 처음 설치할 때 “출처를 알 수 없는 앱 설치”를 한 번 허용해야 합니다.

설치 순서

  1. 위 버튼을 눌러 APK 를 내려받습니다.
  2. 알림이나 다운로드 폴더에서 파일을 엽니다.
  3. “알 수 없는 출처” 안내가 뜨면 설정 → 허용을 누릅니다.
  4. 설치를 누르면 끝입니다. 이후 실행은 홈 화면 아이콘으로.

이 버전의 변경 사항

    업데이트

    1. 게임을 실행하면 새 버전이 있을 때 오른쪽 위에 “새 버전” 배너가 뜹니다.
    2. 배너의 내려받기를 누르면 이 페이지가 열립니다.
    3. 새 APK 를 설치하면 기존 세이브와 설정은 그대로 유지됩니다.
